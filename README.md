# 《山海机关录：墨守》 (Moshou TD)

> 国风机关策略塔防 + 局内肉鸽构筑 (Roguelite Tower Defense)  
> 严格对应主策划案 GDD v2.0 与八阵图专项 GDD v2.1 规范开发。

---

## 一、 快速启动与游玩

本项目采用原生前端技术栈开发，**零外部第三方依赖**，开箱即玩，并深度适配 **移动端手机浏览器（iOS / Android）与电脑端**：

### 方式一：Node 启动本地及手机局域网服务（强烈推荐）
在项目根目录运行：
```bash
npm start
# 或直接运行
node serve.js
```
- **电脑浏览器访问**：[http://localhost:3001](http://localhost:3001)
- **手机浏览器访问**：在手机上连接同一 Wi-Fi，输入电脑局域网 IP（如 `http://192.168.x.x:3001`）即可直接秒开畅玩！
  > 📱 **手机端特色**：
  > 1. 自动全屏自适应等比缩放，无视各种手机刘海/全面屏比例；
  > 2. 具备横屏游玩体验提示；
  > 3. 支持**触控滑动连续拾取**灵气与齿轮（划屏手感极爽）；
  > 4. 右下角大拇指操作轮盘（鲁班拆解钳与机巧过载大招一键释放）。

### 方式二：直接浏览器双击运行
在电脑或手机上直接打开 `index.html` 亦可畅玩！

## 二、 核心特色与系统还原度

1. **5×9 墨家八卦青石阵盘与五行地脉格**：
   - 包含 **火脉格**（+20%攻速与灼烧）、**土脉格**（1%每秒回血与免推免晕）、**水脉格**（25%冷却缩减）、**金脉格**（无视30%护甲破甲）、**木脉格**（100%返还灵气）。
2. **墨家中枢锁阵机制（半继承动态阵盘）**：
   - 棋盘第 2、3 列为“墨家中枢”，通关时机关生命、进化形态与黄金星级直接跨层保留继承！外围机关折算 50% 灵气注入下一层。
3. **8 大墨家机关兽与双分支进化**：
   - 聚灵烘炉（九宫增幅光环 / 烈阳金乌炉 / 乾坤聚宝盆）
   - 诸葛连弩（连发 / 雷公连弩闪电链 / 毒焰重弩毒蚀）
   - 震天埋雷（发条潜伏出土即爆，击退后方 1 格）
   - 玄武重盾（反震伤害 / 熔岩玄武 / 磁暴巨阙电磁冲击）
   - 吞天饕餮（近战秒杀吞噬炼化吐灵气 / 腐骨撕咬 / 炼妖吞天）
   - 寒霜方士（霜冻减速与冰封禁锢 / 玄冥冰魄碎冰斩杀 / 迷魂蛊师倒戈）
   - 暴雨梨花（双发重箭与跨行分裂散射袖箭）
   - 神火飞鸦（烈焰木鸢横扫整行与 5s 灼烧火海）
4. **6 种山海魇魔与两大首领 Boss**：
   - 残破兵俑、藤甲尸兵（惧火引燃200%倍率）、重锤力士（免退破阵）、飞爪山魈（钩爪荡跃撞土脉格晕眩）、狂暴符鬼（符碎霸体狂暴怒吼）、偃师战车（碾压秒杀与抛投火弹）。
   - **九首凶神 · 相柳**（5行多蛇首探头、蓄力打断、断首12秒再生、毒沼格、狂暴蛇蜕化魔）。
   - **断首战神 · 刑天**（2×2 巨型游走、正面玄铁巨盾减伤80%、挥斧露弱点暴击×200%、飞斧裂地3秒预警与QTE拆解空地障碍物）。
5. **天工炉机巧过载**：
   - 击杀积攒 100 能量，消耗 50 能量点击任意机关进入 8 秒超强过载形态！
6. **阵眼石狮与鲁班拆解钳**：
   - 每行底线石狮喷吐烈焰剑气秒杀全行敌人。
   - 拆解钳回收灵气（配合【草木皆兵】词条可化为震天雷引爆）。
7. **八阵图爬塔、诡市鬼谷商铺与 15 大天机赌局事件**：
   - 严格按照 GDD 2.1 动态通胀数学模型定价（层数温和通胀与25层后指数级惩罚）。
   - 15 大叙事事件库（不重复触发保底机制）。
8. **墨门矩子阁局外天赋与信物佩戴**：
   - 天工院、武备堂、奇门局三大天赋树与信物槽，支持本地自动存盘（localStorage）。
9. **国风程序化音效引擎 (Web Audio API)**：
   - 无需下载庞大音频文件，金戈铁马、破空箭矢、齿轮转动、轰鸣爆炸、石狮咆哮纯程序生成！

## 三、 操作指南

- **拖拽/点击布阵**：点击左侧卡牌，再点击棋盘空地即可建造机关。
- **机巧过载**：天工炉能量满 50 点后，点击底部【机巧过载】按钮，再点击场上任意机关施放大招！
- **鲁班拆解**：点击底部【鲁班拆解钳】按钮，再点击场上机关即可拆卸并返还灵气。
- **拾取灵气/刀币**：鼠标滑过或点击掉落的天工齿轮与灵气团自动拾取（点出木鸢巡天天赋后自动吸附）。
- **倍速与暂停**：右上角可自由切换 1X / 2X 战斗速度或暂停思考布局。
